# Nvoip Homebrew Tap

Homebrew tap oficial da [Nvoip](https://www.nvoip.com.br/) para instalar integrações de linha de comando com a API v2.

## Instalação

```bash
brew tap Nvoip/tap
brew install nvoip-shell
```

## Pacotes

- `nvoip-shell`: scripts Linux/macOS para OAuth, saldo, SMS, chamadas, OTP e WhatsApp.
